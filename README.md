# 🔐 Password Security Analyzer

A Python-based password security analyzer that evaluates password strength, detects common weaknesses, and provides suggestions to improve security. This project promotes safer password practices through real-time feedback and scoring.

---

## 🚀 Features

- Password strength scoring
- Detection of common/weak passwords
- Suggestions for improvement
- Password generator
- Simple command-line interface
- Test script included

---

## 📂 Project Structure

```
password-security-analyzer/
│
├── main.py              # Entry point of the application
├── password_checker.py  # Core password analysis logic
├── generator.py         # Password generator
├── common_passwords.txt # List of weak/common passwords
├── test.py              # Test script
└── README.md
```

---

## 🛠 Installation

Clone the repository:

```bash
git clone https://github.com/Saurabhshub/password-security-analyzer.git
cd password-security-analyzer
```

No external libraries required — runs with standard Python.

---

## ▶ Usage

Run the program:

```bash
python main.py
```

Follow the prompts to analyze or generate a password.

---

## 🧪 Running Tests

```bash
python test.py
```
